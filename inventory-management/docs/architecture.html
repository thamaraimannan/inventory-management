Inventory Management System

System Architecture & Data Flow — Factory Demo Application

Tech Stack

Frontend
Vue 3 + Vite
Composition API • Vue Router • Axios
Port 3000 • Custom SVG charts
Backend
Python FastAPI
Pydantic v2 validation • Uvicorn
Port 8001 • Auto OpenAPI docs
Data
JSON Files (In-Memory)
7 JSON files in server/data/
Loaded at startup • No database
Testing & Tooling
pytest + uv
FastAPI TestClient • pytest-asyncio
uv for Python dependency management

Data Flow

1 — User
FilterBar.vue
Selects period, warehouse, category, or status
→
2 — State
useFilters()
Singleton composable; reactive refs shared across all views
→
3 — API Client
api.js
Builds URLSearchParams; Axios GET to localhost:8001
→
4 — Backend
FastAPI
apply_filters() + filter_by_month() on in-memory data
→
5 — Response
Pydantic JSON
Validated typed response; rendered via v-for in template

Global Filter System

Time Period
All Months, Q1–Q4 2025, Jan–Dec 2025
Param: month
Warehouse / Location
All, San Francisco, London, Tokyo
Param: warehouse
Category
All, Circuit Boards, Sensors, Actuators, Controllers, Power Supplies
Param: category
Order Status
All, Delivered, Shipped, Processing, Backordered
Param: status
